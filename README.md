# Google Cloud Learn with Communities

Personal workspace for learning, coding, taking notes, and tracking progress through
the [Google Cloud Learn with Communities](https://cloud.google.com/learn/community) curriculum.

## Repository layout

```text
courses/
├── 01-the-basics-of-google-cloud-compute/
│   ├── README.md
│   └── labs/
│       └── <lab>/README.md
├── 02-configure-service-accounts-and-iam-roles/
...
└── 10-google-deepmind-train-a-small-language-model/
```

Each course README contains the official course link, the current lab count, and a
progress checklist. Each lab README is a notes template with space for objectives,
commands, observations, evidence, and a reflection.

## How to use a lab template

1. Open the lab README under the relevant course.
2. Change `Status` from `Not started` to `In progress` or `Complete`.
3. Record commands and important observations without committing secrets.
4. Add screenshots, exported notebooks, or code in that lab folder when useful.
5. Link related Google Cloud documentation and note any cleanup performed.
